# Screenshots

The finished pages, shot with made-up data unless noted: the repo is public, and the real pages show show names, addresses and connection details. Addresses come from the ranges reserved for documentation (`203.0.113.0/24`, `198.51.100.0/24`, `192.0.2.0/24`), and alert cards marked "demo" come from the pages' own `?demo=` preview.

Mission Control's Connections card is hidden in the sample shots, because the screenshot browser has no WebGL for its 3D globe. The exception is `mission-globe.png`, taken on the real page: it shows real totals and arcs, but no addresses or names.
